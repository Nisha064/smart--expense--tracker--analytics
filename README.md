# 💰 Smart Expense Tracker + Analytics Dashboard

A web-based expense management application that helps users track income and expenses, manage transactions, and understand their spending patterns through an interactive analytics dashboard.

## 🚀 Features

* ➕ Add income and expense transactions
* 🗂️ Categorize expenses
* 📊 View financial summaries and analytics
* 💵 Track total income, expenses, and balance
* 📋 Manage transaction history
* 📈 Analyze spending patterns
* 📱 Responsive and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Structure and layout
* **CSS3** – Styling and responsive design
* **JavaScript** – Functionality, calculations, and data handling

## 📌 Project Purpose

This project was developed to demonstrate practical skills in **frontend development, JavaScript, data handling, UI/UX design, and financial data analytics**.

## 🔮 Future Enhancements

* User authentication
* Database integration
* Budget management
* Expense alerts and notifications
* Advanced charts and reports
* Cloud data storage
* AI-based spending insights
